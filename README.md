🔧 Core Hypothesis
The Voynich Manuscript is generated by a P–C–S system:
PREFIX → CORE → SUFFIX


Where:

Prefixes behave like neumes (musical phrase openers)

Cores supply the structural “body” of the phrase

Suffixes function as cadence markers (line endings, phrase closures)

This PCS model:

Recreates Voynich line length distributions

Produces chant-like contours

Predicts which sequences can or cannot occur

Matches Currier A/B differences through shifts in cadence selection

🧩 Why This Works
1. Text behaves like chant phrasing

Voynich lines match medieval chant phrase lengths:

Typical phrase length: 7–12 units  
Minimum: 5–6  
Upper bound: ~15  

2. Suffixes cluster in cadence positions

ASCII illustration:

[Phrase Body] → [Cadence Suffix]
Example:  qo + kee + dy

3. Currier A vs. Currier B behaves like musical mode shifts
Mode A:
   - Fewer suffix varieties
   - More constrained cores
   - Predictable line shapes

Mode B:
   - Expanded suffix set
   - Higher mutation tolerance
   - Greater phrase variability

4. Botanical & Zodiac drawings follow the same generative logic

Even the illustrations exhibit modular, repeated structures.
They act as visual verses under the same compositional rules.
